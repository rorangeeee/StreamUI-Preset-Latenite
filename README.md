# StreamUI-Preset-Latenite

StreamUICore 0.6.1 / 浏览器 SDK 2 的独立预设。3840 × 2160，包含 21:9、16:9 两个主场景和独立暂离覆盖层，保留常驻页面、弹幕历史、音频图形、字标与像素动效。

## 构建

在 Core 配置页使用「从 Git 安装」，粘贴本预设的仓库地址即可构建预设。Core 会一并安装 `plugins.txt` 列出的桌面音频、系统曲目、OBS 场景联动和 LAPLACE 弹幕插件。

克隆到 Core/presets/latenite：

~~~powershell
npm ci
npm run build
npm test
~~~

构建结果位于 ui/，不提交 Git。源码、默认参数、配置页、锁定文件和构建配置都保留在仓库内。可直接在该工作目录修改 source/ 并重建。

能力依赖来自四个独立源码仓库，先构建再启用预设：
- https://github.com/rorangeeee/StreamUI-Plugin-DesktopAudio
- https://github.com/rorangeeee/StreamUI-Plugin-SystemMedia
- https://github.com/rorangeeee/StreamUI-Plugin-ObsScenes
- https://github.com/rorangeeee/StreamUI-Plugin-Laplace

## 场景配置

两个主场景的配置页提供中英文标题和键鼠显示，暂离场景的配置页提供暂离文字。标题和暂离文字均支持添加、移除多段文字并自动保存。

键鼠显示使用可选的「键盘与鼠标输入」插件（`desktop-input`）。把插件克隆到 Core 的 `plugins/desktop-input`，按插件说明构建并启用，再到任一主场景的「键鼠显示」分别开启键盘、鼠标。[插件源码与构建说明](https://github.com/rorangeeee/StreamUI-Plugin-DesktopInput)

两个主场景共用显示设置，初始均关闭。键盘支持 WASD、方向键 + Shift / Ctrl、左半区、60、75、98 和 108 配列，鼠标可单独关闭移动箭头。配列按常见 ANSI 物理键位绘制，108 配列包含 104 个标准键和 4 个媒体键。

品牌、页脚、标签、信息终端、遮罩透明度与 OBS 绑定保留在默认 JSON 或源码中，不在页面暴露。两个主场景可通过对应 defaults JSON 的 obsSceneName 指定绑定，留空不参与自动联动。暂离不是 OBS 场景，不提供 OBS 绑定。OBS 插件只提供事件，source/src/obs-bindings.ts 实现主场景匹配。

暂离多段文字保存为 texts 数组；没有该数组时，继续读取原来的 text1、text2。已有个人文字无需重新填写。

连接 OBS、弹幕、音频设备等参数属于插件，不存入场景源码默认值。

## 独立预览与暂离

配置页的手动切主场景与重播动效只作用于当前预览。真实 OBS 场景事件也不会带动预览。持久化的文字参数仍共享并即时生效。

sidebar.html 提供 Host 的暂离开关，更新共享预设参数 controls.away：控制实际输出，预览同步显示。它不调用 selectScene，不改变主场景 ID、动效时钟或底层组件生命周期。Core 只提供通用参数保存，不包含暂离业务。

preset.json 的 trayControls 同时将 controls.away 声明为托盘右键菜单中的“暂离模式”。它与预览页开关双向同步并持久保存；Core 只渲染声明的通用开关，具体暂离效果仍由本预设实现。停用本预设后，该托盘入口随之移除。

暂离覆盖层是主转场容器之外的独立层。进入、退出暂离不播放主像素转场；覆盖期间发生的主场景更新直接应用，退出或页面恢复时不补播这些动效。暂离自身的展开、收回和文字滚动保留。

暂离描述声明 role:overlay，仅在“设置 → 场景预设”中提供文字参数，不出现在预览主场景下拉中。选择它的配置不会开启暂离，开关位于托盘右键菜单及“预览”的场景控制区。

同一 runtimeGroup 保持页面常驻；返回普通场景时继续使用同一弹幕历史、组件和播放时钟。

## 字体与更新

直播标题、播放曲目标题及暂离条带的中文使用核心像素体（Hexin Pixel Font，0.1.r60），WOFF2 与完整 OFL 1.1 许可随 source/public/fonts/hexin-pixel/ 分发，无需在系统中安装。直播中文标题按实际加载英文字体的 H 字高匹配“国”的可见字高，并对齐字形中心；字号和字距一起缩放，避免本机英文字体差异造成中文偏高。三处中文均按一个源像素（0.125em）增加字距；曲目和暂离保留按实际可见字高校准、居中及长文本适配。字体保持作者原文件，来源与校验值见字体目录 README。

英文及其他装饰仍使用本机 Retro Pixel、Blue Screen Personal Use、JetBrains Mono 等字体，这些本机字体不在仓库中分发。透明输出根页面使用 color-scheme:normal。

ON AIR 使用固定字重的字形缓存，在 Canvas 中混合字重、伸缩和倾斜，保留原来的播放时钟与录制闪烁。避免在 OBS 33 的 Chromium 150 中逐帧修改 SF Pro 可变字体轴引起的 SVG 排版阻塞。OBS 33.0.1 的 3840 × 2160 / 120 Hz 独立测试中，10 秒采样由约 10.4 FPS 恢复至约 119.9 FPS，修复后没有超过 33 ms 的帧。

OBS 场景动效使用 obs-scenes 1.0.1 的目标场景事件及转场开始时间，不等待 Stinger 视频结束；预览仍忽略真实 OBS 场景事件。

更新前提交或暂存自己的源码修改，合并所选 Git 版本后执行 npm ci、npm run build，再刷新预览和 OBS。修改清单结构后刷新列表并重新启用预设。

从旧版升级时，停止 Core 并运行：

~~~powershell
npm run migrate -- <Core数据目录>
~~~

该脚本迁移旧标题、主场景 OBS 绑定和暂离文字，保留已有自定义。旧版选中的暂离场景会转为 controls.away 开关，主场景恢复正常布局；原配置保留备份。完成标记避免重复导入。Core 和能力插件各自负责自己的数据，不在本预设中保存连接密码。

## 验证

npm test 验证空绑定、仅一个绑定、预览隔离、参数适配和旧设置迁移。Core 中可运行 npm run extensions:check -- <本仓库目录> 检查源码仓库格式。

## 2.2.4 标题动效

两种布局的中英文标题均采用 lab/title-extension 的笔画横向生长、水平模糊与中点变色切换。字形不拉伸，字距最多收缩至 75%；保留原来的 6.9 秒停留、1.6 秒切换节奏。品牌字标继续使用原动效。

中文继续使用核心像素体，与英文按可见字高匹配，字距采用实验版的 1.1666667em。逐字定位按可见墨迹居中，避免 SVG 尾部字距使中文偏移。21:9 保留顶栏中心，16:9 保留画布顶部中心；原有标题字号、基线及长标题缩放规则保留。减少动态效果偏好与页面隐藏时暂停沿用现有逻辑。

## 2.2.5 标题头尾平滑

在相邻整数膨胀半径之间按实际设备像素插值，消除小半径阶段的阶梯变化。小于 4px 的水平模糊也在相邻核之间连续混合；膨胀插值在 2–4px 模糊区间逐渐退出，中段保留原滤镜输出。插值会适应画布缩放和设备像素比，静止状态继续释放滤镜。标题尺寸、居中、基线、字距和播放时长与 2.2.4 相同。

## 2.2.6 键鼠显示

两个主场景新增键盘和鼠标显示，支持七种键盘布局、持续按键高亮、鼠标滚轮和 360° 移动箭头。在任一主场景的配置页分别开启键盘与鼠标，显示设置会在两种画幅之间共享。
